# 代发履约明细与管理总览分层设计

## 目标

让同一份 1688 周期履约数据在两个场景中各司其职：业务台账完整保留原始事实，管理总览只呈现影响判断与行动的指标。修复导入过程中的百分比、时间值和供应商名称不一致问题，并支持对已建档记录进行原表回填。

## 范围

- 调整代发周期履约的 Excel 解析、预览、归档和展示。
- 业务明细展示完整采集字段及来源。
- 管理总览展示聚合指标、风险、趋势和建议动作。
- 以“江苏新丰之星膜材料有限公司”为兼容回填验证样本。
- 不改采购主流程，不自动合并未经确认的供应商别名，不引入财务结算功能。

## 数据导入规则

### 数值转换

- 百分比列兼容 Excel 原始小数和已乘 100 的数值：`0.143` 解释为 `14.3%`，`14.3` 仍解释为 `14.3%`。
- `100%` 对应的 Excel 数值 `1` 必须显示为 `100%`，但普通计数字段不做该转换。
- 平均退款时长若为 Excel 时间小数，按一天 86400 秒换算；若源值已经是秒数则直接保留。
- 空白保持为空，真实零值保持 `0`，页面分别显示“未采集”和“0”。

### 供应商合并

- 精确名称继续自动合并。
- 相似名称只给出“建议关联”，不得自动合并。
- 用户确认一次别名关系后，后续导入复用该映射。
- 同一周期内，商家服务数据与售后数据归并到同一供应商周期记录。

### 历史数据回填

- 再次导入相同平台、周期和供应商时，更新原周期记录，不新增重复记录。
- 已建档但字段缺失的记录，从本次原表补齐。
- 已存在的人工录入字段不得被空白源值覆盖。

## 业务明细

业务明细按供应商、平台、周期展示：

- 规模：支付订单量、GMV。
- 交付：48H 揽收率、支签时长、支签时长变化。
- 售后服务：退款率、拒退率、3 分钟响应率、售后量、售后率、售后拒绝量、售后拒绝率、平均退款时长。
- 平台评价：灯塔售后、品质、综合服务分。
- 证据：源文件、工作表、原始行号、导入时间、别名关联说明。

表格列表保留核心列，点击详情后显示全部字段。缺失值显示“未采集”，零值显示明确的 `0` 或 `0%`。

## 管理总览

管理总览只展示决策字段：

- 当前周期订单量、GMV、有效样本供应商数。
- 加权 48H 揽收率、加权退款率/售后率。
- 风险供应商数量及风险类型。
- 供应商排名变化或指标趋势；只有一个周期时标记“暂无趋势”。
- 每个风险项展示供应商、样本量、关键异常、建议动作和进入业务明细的入口。
- 待建档、样本不足、别名待确认分别计数，不混入正式绩效排名。

管理总览不得把空值按零参与加权或风险判断。

## 错误与边界处理

- 表头缺失时阻止该工作表导入，并列出缺失列。
- 同名候选超过一个时要求人工选择。
- 售后表与商家表无法确认归属时分别保留在待确认区，不丢弃数据。
- 回填前后保留来源证据和处理时间，支持追溯。

## 验收标准

1. 江苏新丰周期明细能显示源表中的 40 单、GMV 555.5、100% 揽收、53.4 小时、14.3% 退款、0% 拒退和 0% 响应。
2. 人工确认“新丰之星装饰材料”为江苏新丰别名后，售后量 3、售后率 11.54%、平均退款时长及灯塔分进入同一周期记录。
3. 明细页完整显示采集字段，空值与零值区分。
4. 管理总览只显示聚合、风险、趋势和行动，不堆放全部原始字段。
5. 重复导入同一文件不会生成重复周期记录。
6. 解析、归档、回填和两个页面均有自动化测试。
