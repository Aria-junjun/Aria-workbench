# 代发供应商周期履约统一导入设计

## 目标

在供应商业务台账的“代发周期履约”中提供统一 Excel 导入口。一次上传后，系统按供应商、统计周期和平台归档商家履约与售后数据，并把无法安全匹配的商家送入待建档区。商品履约数据保留为周期商品分析，不在缺少关系依据时强行归属供应商。

本阶段不接逐笔订单、不接财务结算，也不自动抓取 1688 数据。

## 本次数据口径

- 测试周期：2026-09-04 至 2026-09-18。
- 平台：导入时由用户选择，首次测试默认 1688。
- 本次周期标记为“历史测试周期”。
- 后续新增导入默认按自然周生成日期，但允许修改。
- 售后率沿用来源定义：申请售后的单量（退货退款、退款、补发、换货）除以支付订单量。
- 灯塔分保留平台原始值，并注明其考核周期可能与所选业务周期不同，不与周度指标强行同口径计算。

## 文件解析

系统按表头识别三类工作表，不依赖 Sheet1、Sheet2、Sheet3 的固定名称：

1. 商家履约：商家、主单/GMV、48H 揽收率、支签时长、退款率、拒退率、3 分钟响应率。
2. 商品履约：商品信息、主单/GMV、48H 揽收率、支签时长、退款率、拒退率。
3. 商家售后：商家名、售后量、售后率、售后拒绝量、售后拒绝率、平均退款时长、支付订单量及灯塔分。

解析器必须处理合并单元格产生的附加提示行。例如“↑31H”“↓6pp”应合并到上一条记录，不能生成独立供应商。百分比、人民币、订单数和小时数统一转换为可计算数值，同时保留来源文件名、工作表名和原始行号。

## 导入流程

1. 用户点击“批量导入周期履约”。
2. 填写或确认统计开始日期、结束日期、平台/店铺及周期备注。
3. 上传 `.xlsx`、`.xls` 或 `.csv` 文件。
4. 系统解析并展示预览：有效记录、异常行、精确匹配、建议匹配、待建档、商品记录。
5. 用户确认供应商建议匹配；未确认项保持待建档，不进入正式供应商档案。
6. 用户确认导入后一次写入。取消操作不改变现有数据。
7. 页面显示导入结果和失败原因，不以静默保存作为完成状态。

## 供应商匹配与建档

匹配优先级：

1. 已确认的平台商家 ID；
2. 标准化后的供应商全称精确匹配；
3. 已确认别名匹配；
4. 名称近似时仅给出建议，不自动关联；
5. 无可靠候选时进入待建档区。

待建档区按一个统计周期内的支付订单量分层：

- 少于 20 单：样本不足，不建议建档。
- 20 至 99 单：达到观察门槛，显示“建议建档”，仍需人工确认。
- 100 单及以上：重点供应商候选，参与正式绩效评价，仍不自动建立档案。

人工可覆盖门槛，处理低频定制、战略备份或高金额供应商。订单量门槛仅是流程门槛，不代表供应商质量结论。

## 数据归档

### 商家周期履约

以“平台/店铺＋统计开始日＋统计结束日＋供应商”为业务唯一键。商家履约和商家售后能可靠匹配到同一供应商时，合并为一条周期记录，但分别保留来源工作表和原始口径。

同一业务唯一键再次导入时进入覆盖预览，不重复累加。只有用户确认后才更新记录。

### 商品周期分析

商品履约表没有供应商字段，因此本阶段独立保存为周期商品表现记录。只有存在明确商品链接、商品 ID 或人工确认关系时，才能关联供应商。不得按排名或文本相似度自动建立商品—供应商关系。

### 产品下架

产品下架不删除任何历史事实：

- 供应商—产品关系转为“已结束/产品下架”；
- 保留历史周期履约、售后、报价、样品和合作记录；
- 供应商仍有其他在售产品时保持正常档案；
- 无其他在售产品时进入“历史供应商/已存档”；
- 存档供应商后续重新合作时可恢复，不新建重复档案。

## 页面设计

在“代发周期履约”页签右侧增加“批量导入周期履约”，保留现有单条新增作为补录入口。

导入预览使用与采购板块一致的有边框表格，主要区域包括：

- 导入口径：周期、平台、文件名、来源工作表；
- 汇总：商家数、商品数、精确匹配数、待确认数、待建档数、异常行数；
- 供应商匹配表：来源名称、订单量、匹配状态、候选档案、人工选择；
- 异常表：原始行号、问题、处理建议；
- 确认区：新增、覆盖、跳过数量及确认导入按钮。

待建档区提供样本层级、订单量、GMV、关键风险和“建立档案/关联已有/继续观察”操作。

## 校验与错误处理

- 统计开始日不得晚于结束日。
- 必须选择平台并上传支持的文件格式。
- 缺少必需表头时阻止确认导入，并指出工作表和缺失列。
- 空值与 0 分开处理；缺失值不计作零表现。
- 比率限定在 0 至 100，订单量、金额和时长不得为负数。
- 文件内重复商家先提示，不静默合并冲突数据。
- 任何解析失败都保留原文件，不部分写入正式台账。

## 测试范围

- 三种表头识别及非固定工作表名称。
- 合并单元格附加提示行合并。
- 订单/GMV、百分比、小时和灯塔分解析。
- 供应商精确匹配、别名、近似建议与未匹配。
- 20 单和 100 单边界。
- 同周期重复导入覆盖预览与幂等写入。
- 商品数据不被错误归入供应商。
- 产品下架后历史记录仍可追溯。
- 页面预览、取消不写入、成功提示和错误提示。

## 验收标准

使用《代发供应商履约表.xlsx》导入时，系统正确识别三类各 30 条主体记录，不把附加提示行当作新记录；用户能在一次预览中完成供应商归位，确认后匹配记录进入周期履约，未匹配记录进入待建档区，商品记录进入周期商品分析。重复导入不会产生重复周期记录。
