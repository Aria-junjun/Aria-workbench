# 供应商决策优先级调整设计

## 目标

让供应商决策总览只对真实的供应链问题产生动作，不把产品族中尚未采购或尚未映射的 SKU 数量误判为供应商风险。

## 决策规则

供应商动作按以下优先级生成：

1. **待补供应商归属**：存在实际入仓记录，但未明确实际供应商。
2. **复核主供/备供**：同一产品族在统计周期内由多个供应商实际供货。
3. **复核质量信号**：退货率达到阈值，且数据能够追溯到供应商；产品级退货率在无法归因时只作为产品信号展示。
4. **保持主供**：没有触发以上真实问题。

SKU 覆盖不再生成“补齐未覆盖 SKU”动作，只作为辅助信息展示：

`实际供货 SKU 数 / 产品族 SKU 总数`

## 页面呈现

- 决策筛选中移除“补齐未覆盖 SKU”。
- 表格中的“SKU覆盖”改为“实际供货 SKU”，避免暗示供应商必须覆盖整个产品族。
- 保留产品退货信号列；无供应商归因时明确标注为产品层信号。
- 下一步链接只指向真实需要处理的供应商归属、主备供关系或质量核验。

## 数据边界

- 产品族 SKU 总数来自内部 SKU 主表，仅用于参考。
- 实际供货 SKU 数来自统计周期内的入仓记录。
- 质量信号来自周期经营快照；供应商归因必须有明确的入仓供应商关系。
- 不因报价、MOQ、交期字段为空就直接判定供应商异常，因为实际供货本身证明供应关系存在。

## 验证标准

- 单一供应商实际供货但未覆盖全部产品族 SKU：动作应为“保持主供”，不出现补齐覆盖待办。
- 多供应商实际供货：动作应为“复核主供/备供”。
- 未标供应商的实际入仓：动作应为“待补供应商归属”。
- 质量信号有明确供应商归因时可触发质量复核；无归因时只能显示产品信号。
