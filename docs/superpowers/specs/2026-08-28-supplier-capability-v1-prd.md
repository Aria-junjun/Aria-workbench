# 供应商能力网络 V1 PRD

## 1. 背景

当前供应商页面已经具备供应关系、货盘、入仓、销售和基础决策，但供应商能力、备用供应商筛选和新品开发复用尚未形成闭环。V1 只补齐最能改变决策的能力档案，不扩展为采购或库存系统。

## 2. 用户目标

- 查看某供应商能做哪些产品、工艺、材料和设备。
- 查看某产品族有哪些候选、备用和已合作供应商。
- 根据实际表现判断是否保持、扩品、晋级核心或复核。
- 从产品机会反查可复用工艺和供应商，支持打样与联合开发。

## 3. 页面要求

### 供应商列表

按“需要处理、正常合作、备用供应商、候选供应商、暂无有效证据”分组，字段只保留供应商名称、角色、实际供货产品族、本期入仓、主要信号和下一步动作。评分降为辅助信息。

### 供应商详情

固定五个区域：供应商概况、供应商能力、实际供应关系、经营与证据、决策与发展动作。货盘报价单独展示，不与实际供应关系混为一谈。

### 供应商能力

支持维护产品族、工艺、原材料、设备、规格范围、MOQ、交期、打样能力、定制能力、来源和有效期。能力记录可失效，但不能破坏历史决策。

### 产品机会联动

产品机会详情可按产品族、工艺、材料和设备查询匹配的供应商能力，结果分为“已合作、备用、候选、待验证”。V1 只提供匹配和人工确认，不自动断言供应商一定可生产。

## 4. 决策规则

- 已有稳定实际供货且无新异常：建议保持合作。
- 备用供应商具备目标产品族能力且有报价或验证证据：允许进入备选池。
- 连续周期表现稳定、质量和交付证据完整、能力覆盖扩大：可提出晋级核心供应商。
- 产品退货率异常：生成质量复核信号，不直接归因供应商。
- 供应商工艺、材料、设备与产品机会匹配：允许提出新品打样动作。

## 5. 成功标准

用户在一个供应商详情页内能够回答“供什么、能做什么、表现如何、还能不能做更多”；在一个产品机会内能够找到具备匹配能力的已有供应商；所有判断都能回到来源或人工确认记录。
