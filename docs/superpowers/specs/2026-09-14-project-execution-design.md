# 项目推进模块设计说明

## 定位

项目推进承接产品拆解产生的方案与行动，将其转化为可执行、可跟踪、可复盘的项目计划。它独立于产品拆解，但允许引用产品拆解项目和带入行动项。

## 五步流程

1. 项目定义：背景、目标、成功标准、范围与排除项。
2. 干系人分析：角色、职责、影响力、关注度与沟通方式。
3. 约束与范围：质量、时间、成本，以及不可妥协项和资源限制。
4. 计划与里程碑：任务、负责人、日期、依赖、交付成果与里程碑。
5. 风险与复盘：风险、概率、影响、应对措施和项目复盘记录。

## 边界

第一版不做自动排期、资源冲突计算、自动分配负责人和复杂权限；系统保存判断与执行事实，不替用户做项目决策。
