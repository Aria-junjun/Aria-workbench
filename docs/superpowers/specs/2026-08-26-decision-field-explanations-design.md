# 产品与供应商页面：决策字段说明区块

## 目标

减少产品页和供应商页的解释性占位内容，让页面优先服务于经营判断；同时保留数据来源、计算口径和字段边界，避免用户误解指标。

## 范围

- 产品主页面：将“数据来源与汇总口径”改为紧凑的“数据口径”区块。
- 供应商页面：将评分及决策说明收敛为紧凑的口径入口，不新增评分逻辑。
- 对实际入仓、退货率、供应关系、建议动作等决策字段增加问号说明。
- 不删除原始数据、不改变现有计算公式、不引入库存推算。

## 交互与内容

1. 页面默认展示决策数据和动作；数据口径以小区块呈现。
2. 问号说明使用原生悬浮提示，鼠标悬停或键盘聚焦可查看。
3. 当前只接收入仓数据时，库存/可售不作为决策字段，不在主页面制造“待采集”噪音。
4. 说明文案必须与当前数据来源一致：实发/实退来自月度经营表，实际入仓来自入仓或供应商对账表，供应关系来自已保存的持续关系。

## 验收标准

- 产品页不再出现占据大面积的三张口径说明卡片。
- 供应商页不因缺少库存数据显示无效的库存提示。
- 关键字段均能通过问号看到用途和数据来源。
- 页面数据和现有测试结果保持不变。
