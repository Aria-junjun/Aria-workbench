# 商业知识书架封面设计

## 目标

让书架通过真实封面快速识别书籍，同时保持当前本地 MVP 的录入流程简单，并为未来迁移到云端图片存储保留清晰的数据边界。

## 功能范围

- 书籍导入预览页支持选择 JPG、PNG 或 WebP 封面。
- 已入库书籍的详情页支持补充、替换和删除封面。
- 书架卡片以固定书籍比例完整展示封面，不裁切原图；无封面时展示统一占位样式。
- 封面作为书籍字段保存，现有无封面书籍继续正常使用。

## 图片处理

- 浏览器本地读取图片，不上传到第三方服务。
- 使用 Canvas 等比缩放，最长边不超过 720px。
- 优先转为 WebP，并控制压缩质量，避免原始大图占用 localStorage。
- 拒绝非图片文件，并对处理失败给出中文提示。

## 数据结构

`KnowledgeBookDraft` 与 `LocalKnowledgeBook` 增加可选字段 `coverImage?: string`。当前字段保存压缩后的 Data URL；未来迁移到 Supabase Storage 时，该字段可以替换为对象存储 URL，不改变书籍、决策工具和应用记录之间的关系。

## 界面行为

- 导入页：在确认书籍信息区域显示封面选择器和预览。
- 详情页：封面旁提供“更换封面”和“删除封面”。修改立即保存到本地书籍记录。
- 书架：采用紧凑左右结构，左侧封面固定为竖版 `2:3` 且禁止被 Flex 拉伸，右侧依次显示书名、作者、三行摘要和统计信息；卡片不设置额外最小高度，也不跟随同排的其他卡片拉伸。图片使用 `object-contain` 完整显示，轻微比例差异产生的空间由浅灰背景填充；移动端保证标题、作者和统计信息不被遮挡。

## 风险与边界

- localStorage 容量有限，因此不保存原始图片，也不支持一次上传多张图片。
- 本次不做联网搜索封面、自动识别书名找封面、复杂裁切和图片编辑。
- 数十本书通常可承载，但正式云端版本应把封面迁移到对象存储。

## 验收标准

1. 新书可以带封面入库并在书架、详情页正确显示。
2. 已有书籍可以补充、更换和删除封面。
3. 刷新页面后封面仍然存在。
4. 无封面的旧书不报错，并显示占位封面。
5. 数据兼容测试、封面处理测试和生产构建通过。
