# 货盘报价页：列表与 SKU 比价设计

## 结论

在现有“货盘库”和既有“生成对比表”能力上做增量优化，不删除现有货盘数据、不重做左侧导航、不改变当前云端视觉风格。

第一阶段只解决一个问题：让同类货盘可以按产品/SKU聚合并横向比较。

## 现状与问题

当前页面已经具备搜索、筛选、置顶、勾选货盘和生成对比表能力。现有数据同时包含结构化报价和整段1688/人工文字，且同类商品可能以多条独立货盘记录存在。

主要问题：

- 卡片内容过长，不适合快速比较。
- 同类商品分散在多条记录中。
- MOQ、交期、运费等字段存在缺失或未标准化。
- 用户无法快速判断一条货盘是否已经关联产品、SKU和供应商评分。

## 保留范围

必须保留：

- 现有货盘记录及原始报价文字。
- 搜索、置顶、筛选、勾选、打开1688链接。
- 现有货盘详情页和卡片视觉语言。
- 已有的“生成对比表”入口和本地/云端数据同步。

本次不做：

- 不删除或批量合并现有货盘。
- 不接入聚水潭。
- 不自动生成正式供应商评分。
- 不自动确认低置信度的相似商品匹配。
- 不重做首页和左侧导航。

## 页面结构

### 顶部工具区

保留现有搜索框，增加：

- `新增货盘`
- `导入报价`（第一阶段可先保留入口，不要求实现文件导入）
- 视图切换：`货盘列表`、`SKU比价`、`供应商报价`

### 筛选区

保留现有供应商/商品快捷筛选，并增加状态筛选：

- 全部
- 待确认
- 已关联产品
- 未关联产品
- 一件代发
- 入仓

### 指标区

展示四个轻量指标：

- 货盘总数
- 已关联SKU
- 待确认货盘
- 供应商数量

指标只作为当前筛选结果的摘要，不新增独立统计系统。

## 视图设计

### 1. 货盘列表视图

将当前卡片压缩为列表行，默认展示：

| 字段 | 说明 |
|---|---|
| 商品/货盘名称 | 保留原始名称，过长时截断 |
| 供应商 | 可点击进入供应商详情 |
| 报价 | 优先显示已识别价格，无法识别时显示待整理 |
| MOQ | 未记录时显示未记录 |
| 交期 | 未记录时显示未记录 |
| 关联状态 | 已关联、待确认、未关联 |
| 更新时间 | 使用现有更新时间 |
| 操作 | 查看、加入对比、关联产品 |

原始整段报价不丢失，放入详情抽屉的“原始资料”区域。

### 2. SKU 比价视图

用户先选择一个产品/SKU，再展示相关供应商报价：

| 字段 | 说明 |
|---|---|
| 供应商 | 当前报价对应供应商 |
| 采购价 | 已识别的价格或价格区间 |
| 运费 | 未记录时不参与到手成本计算 |
| 到手成本 | 只有成本字段完整时计算，否则标记不完整 |
| MOQ | 数值或原始文本 |
| 交期 | 标准化天数或原始文本 |
| 供应商评分 | 暂无实际合作数据时显示暂无评分 |
| 数据状态 | 当前、待确认、已过期 |

现有“勾选后生成对比表”继续保留，作为跨货盘的快速比较入口；SKU比价视图用于长期查看同类报价。

### 3. 供应商报价视图

按供应商聚合展示：

- 货盘数量
- 已关联SKU数量
- 报价数量
- 平均或主要交期
- 当前评分（若存在）
- 最近更新时间

点击供应商后进入其报价明细，不在列表页展开全部长文本。

## 详情抽屉

点击列表行的“查看”后，在当前页面打开右侧详情抽屉，包含：

1. 基础信息：商品名、供应商、1688链接。
2. 已识别字段：报价、MOQ、交期、规格、运费。
3. 关联信息：产品、SKU、供应商评分、相关任务。
4. 数据状态：来源、录入时间、更新时间、是否待确认。
5. 原始资料：完整报价文字和备注。
6. 操作：关联已有产品、创建新产品、加入比价、生成跟进任务。

## 数据状态与结构化策略

不强制一次性整理所有历史数据，采用渐进式状态：

- `structured`：关键字段已经识别。
- `partial`：部分字段识别成功，仍保留原始文字。
- `pending_review`：无法可靠识别，需要人工确认。
- `expired`：存在历史报价，但不是当前有效报价。

缺失数据统一显示“未记录”，不能默认当作0，也不能默认当作低风险。

## 关联规则

第一阶段只提供明确的人工关联入口：

- 货盘 → 关联已有产品/SKU。
- 货盘 → 创建新产品待完善。
- 货盘 → 关联供应商。
- 货盘 → 生成跟进任务。

后续再增加自动匹配。低置信度匹配只能显示候选，不得自动合并。

## 交互流程

```text
搜索商品或供应商
→ 切换到货盘列表
→ 查看同类货盘
→ 选择一个产品/SKU
→ 进入SKU比价
→ 查看价格、MOQ、交期和评分
→ 打开详情抽屉
→ 关联产品/SKU或生成任务
```

## 成功标准

- 现有货盘数据全部仍可查看。
- 用户可以在列表中快速比较同类货盘。
- 用户可以按SKU查看多个供应商报价。
- 原始报价文字仍然可追溯。
- 用户能看出哪些数据已结构化、哪些需要确认。
- 货盘可以关联产品、SKU、供应商和任务。
- 现有搜索、置顶、筛选和对比入口不受影响。

## 后续扩展

在第一阶段稳定后，再增加：

- 报价版本与历史变化。
- 供应商成本评分证据。
- 1688数据导入。
- 聚水潭实际采购和履约数据。
- 自动更新供应商评分。
