# 月度经营快照设计

## 目标

让入仓产品按月保存 SKU 经营数据，产品族自动汇总本月结果并支持环比比较；不依赖聚水潭日常自动同步，也不覆盖历史月份。

## 范围

- 保留当前 SKU 基础资料、货盘、供应商关联和供应决策。
- 新增按 `YYYY-MM` 保存的 SKU 月度经营快照。
- 录入入口放在“入仓产品主表”的产品族展开区域。
- 产品族层展示所选月份的合计/加权结果和与上月的变化。
- 暂不接聚水潭 API，不复制订单明细，不做每日数据任务。

## 数据口径

- 月销量、销售额、缺货次数：同一产品族的 SKU 求和。
- 毛利率：按销售额加权；没有销售额依据时显示待采集。
- 库存天数、退货率：对有值的 SKU 取平均。
- 供应商成本、MOQ、交期：继续来自已确认的 SKU—货盘—供应商关联，不进入经营快照。
- 月度快照一经保存保留历史；同一 SKU、同一月份再次保存时更新该月份版本。

## 页面

- `/product-master`：月份选择、保存快照、产品族汇总、环比标记、SKU明细录入。
- `/products/[productId]`：沿用现有产品详情，后续可增加趋势图；本次先不扩展无明确数据源的页面。
- `/sku-master/import`：继续只负责基础 SKU 表和货盘关联，不承载月度经营数据。

## 风险控制

- 没有数据的月份显示“待采集”，不补零、不伪造趋势。
- 旧版直接保存在 SKU 上的经营字段作为当前值兼容读取；首次保存月度快照时可作为当月初始值。
- 未来接入聚水潭时只替换快照数据的来源，不改变页面和汇总口径。
