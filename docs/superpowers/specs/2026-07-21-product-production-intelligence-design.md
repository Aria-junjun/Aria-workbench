# 产品生产端知识库设计

## 目标

产品知识库用于沉淀采购时难以直接看见的生产端知识，支持询价、打样、验货、供应商沟通和产品判断。它不再承担理论成品成本测算。

## 核心原则

- 价格只记录用户从 1688、供应商报价或实际采购中获得的真实批发报价。
- 不再根据公开原料价格推算产品硬成本，不展示理论成本合计。
- 默认调研聚焦已经成熟、能够指导当前工作的生产知识。
- 新技术和替代风险按需分析，不在每次产品录入时自动生成，以控制 Token 和信息噪声。
- 已有原始资料不删除；旧成本字段保留在原始数据中，但不继续作为前台判断依据。

## 默认产品知识结构

### 产品与关键规格

- 产品名称、用途和使用场景。
- 会显著影响质量、工艺或采购报价的规格参数。
- 缺失关键参数时先提出少量必要问题，不自行猜测。

### 1688 采购参考

- 真实批发报价、对应规格、MOQ、是否含运费和报价时间。
- 不同规格或数量档位分别记录。
- 未获得真实报价时显示“待询价”，不生成估算单价。

### 原料与结构

- 产品使用的主要材料、辅料和结构层次。
- 各材料或结构的功能、等级差异及主要产业带。
- 影响质量、寿命和加工适配性的关键参数。

### 生产流程与设备

- 从原料到成品的主要生产步骤。
- 每道关键工序的作用、使用设备和技术难点。
- 关键质量控制点及常见异常。

### 缺陷与风险

- 成品常见缺陷。
- 原料固有弊端。
- 工艺导致的质量问题。
- 使用和售后风险。

### 成熟替代与优化

- 已有实际应用基础的替代材料、结构或工艺。
- 明确说明替代对象、改善目标、效果保持依据、实现条件、新风险和验证方式。
- 不输出缺乏依据的“更换材料”“优化包装”等泛泛建议。
- 不强制预测节省金额；没有可靠依据时不量化。

### 采购与验证

- 向供应商必须确认的问题。
- 打样和验货重点。
- 影响报价和质量的关键变量。
- 是否值得继续询价、打样或深入调研。

## 按需趋势分析

产品详情提供“分析技术趋势与替代风险”入口，由用户主动调用。内容包括：

- 当前主流技术路线及采用原因。
- 市场中已有的其他生产方式及成熟程度。
- 正在进入市场的新材料、新结构、新设备和新工艺。
- 当前产品、原料或工艺可能被替代的条件和影响范围。
- 需要持续观察的供应链和市场信号。

趋势信息必须区分已验证事实、公开行业动向、合理推断和无法确认事项。来源、日期、应用阶段和可信程度保留在后台；前台优先展示结论、影响和建议动作。

## 页面与导出

- 产品详情按默认知识结构展示，不再展示理论材料成本表或硬成本合计。
- 产品对比只比较规格、原料结构、工艺、设备、质量风险、成熟替代方案和真实采购报价。
- 产品知识简报沿用同一结构，避免页面和导出使用两套口径。
- 趋势分析没有执行时不显示空白模块。

## 兼容与验证

- 旧产品记录继续可读取，原始成本资料不丢失。
- 导入解析能够读取新的统一格式，并保留无法归类的原文。
- 测试覆盖提示词结构、导入解析、旧数据兼容、详情展示、产品对比和知识简报。
- 未接入 API 时，趋势入口应说明需要在 ChatGPT 整理后导入，不伪装成已经完成自动分析。
