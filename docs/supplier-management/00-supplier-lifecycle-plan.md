# 供应商全周期管理总规划

## 1. 目标

围绕产品需求、供应商关系、采购执行、经营结果和改善动作，建立一条可追溯的供应链决策闭环。系统不替代聚水潭的采购、库存和财务功能，只承接本工作台能够获得并用于决策的数据。

## 2. 全周期流程

```text
产品需求 → 产品族/SKU → 供应商寻源 → 准入与关系确认
        → 采购/实际入仓 → 销售/退货 → 绩效判定
        → 保持/备供/改善/复核/淘汰 → 新品打样与联合开发
```

## 3. 分阶段范围

### M1：最小事实闭环

使用现有销售、实际入仓、退货和供应关系数据，输出产品族与供应商的经营对比。库存、交付、成本、沟通和改善没有来源时显示“未采集”，不补零、不评分。

### M2：供应商绩效闭环

增加订单承诺日期、实际交付、质量问题、沟通时间戳和改善节点，按本规划的基准值生成达标、预警、超时和无法判断。

### M3：供应商发展与产品协同

增加能力档案、工艺、原材料、设备、打样和联合开发记录，用于产品机会反查供应商，但匹配结果必须经过人工确认。

## 4. 决策原则

- 事实优先于评分；评分是摘要，不是结论。
- 有基准、有实际值、有责任归属，才能判定。
- 退货率首先是产品质量信号，不能自动归因给单一供应商。
- 正常保持主供不生成提醒。
- 每个结论必须能回到原始数据、计算过程或人工确认记录。
