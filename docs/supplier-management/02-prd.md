# 供应商全周期管理 PRD

## 1. 用户目标

用户能够回答：供应商供什么、实际表现如何、问题证据是什么、下一步应该做什么，以及是否适合承担更多产品或参与新品开发。

## 2. 页面结构

### 供应商总览

默认按以下优先级排序：质量异常、交付超时、供应关系缺失、改善逾期、数据不足、正常保持主供。正常供应商弱化显示，不生成待办。

字段：供应商、供货产品族、主供/备供、周期销售、实际入仓、退货率、绩效状态、证据、下一步动作。

### 供应商详情

固定区域：供应商概况、供应关系、经营表现、绩效明细、改善事项、能力档案、导出。

### 绩效明细

前端显示公式结果；点击“查看细则”或“导出明细”时，必须完整呈现原始值、基准值、计算公式、结果、证据来源、责任归属和数据缺失情况。

## 3. 标准值与判定规则

以下为 M2 的公司默认基准，订单或合作协议存在明确约定时优先使用约定值。所有标准值应可配置并保留生效日期。

### 交付

所需字段：需求日期、供应商承诺日期、实际入仓日期、约定数量、实际入仓数量。

```text
按时 = 实际入仓日期 ≤ 供应商承诺日期
按时足量 = 按时 且 实际入仓数量 ≥ 约定数量
延期天数 = 实际入仓日期 - 供应商承诺日期
```

状态：按时足量、按时不足、延期交付、部分延期、无法判断。没有承诺日期时不评价及时性。

### 沟通响应与问题解决

首次有效响应默认工作时间基准：紧急事项 2 个工作小时，普通事项 1 个工作日，非紧急事项 2 个工作日。该标准只用于首次响应，不代表问题解决时限。

```text
首次响应达标 = 首次有效回复时间 - 消息发出时间 ≤ 对应响应 SLA
问题解决按期 = 验证通过时间 ≤ 双方确认的承诺解决日期
问题闭环达标 = 问题解决按期 且 验收通过
```

“回复”必须是有效回复；自动回复、已读和无实质内容的回复不计入。没有双方确认的解决日期时，问题解决时效显示“无法判断”，不套用首次响应 SLA。

### 改善

状态：待制定、已制定、进行中、待提交验证、验证不通过、已完成、已逾期。

```text
按期完成 = 截止日期前提交 且 验证通过
改善完成率 = 已完成并验证通过的事项 ÷ 已到期事项总数
```

未到期事项不进入分母；没有截止日期的事项不能判定逾期。

### 质量

当前可用公式：

```text
退货率 = 实退数量 ÷ 实发数量 × 100%
```

退货率达到 5% 触发“质量复核”信号。该信号属于产品层质量信号，不自动认定供应商责任。

### 成本

供应商成本核验分开保存三类价格：本地已确认货盘报价/采购约定价作为基准价，供应商结算单作为实际采购价，聚水潭 ERP 成本价作为包含仓库成本的内部参考，不直接用于供应商评分。

```text
基准采购成本 = 已确认基准单价 × 实际采购数量
实际供应商成本 = 结算金额 + 已确认供应商责任增量成本
成本偏差率 =（实际供应商成本 - 基准采购成本）÷ 基准采购成本
```

供应商责任增量成本包括延迟代发、加急运输、质量返工、补发和售后处理等有证据且已确认归责的费用。无法确认责任的费用只保留为待核验事件，不进入评分。成本偏差率评分为：≤0% 得 100 分，0–3% 得 95 分，3–5% 得 85 分，5–8% 得 70 分，8–12% 得 50 分，>12% 得 30 分。缺少基准价、结算价或采购数量时成本为 N/A。

### 评分启用条件

```text
有基准值 + 有实际值 + 有明确责任归属 = 可评分
否则 = 未采集/无法判断
```

评分只汇总已经具备判定条件的指标；不能用满分替代缺失数据。

## 4. 评分规则

无问题、无任务或无对应事实的指标统一为 N/A（不适用），不记 0 分，也不虚构 100 分。有效指标加权公式：

```text
最终评分 = Σ（有效指标得分 × 指标权重）÷ Σ（有效指标权重）
```

若本期没有任何有效指标，综合评分显示“无法评分”，不生成等级。

## 5. 导出要求

供应商导出至少包含：供应商信息、供应关系历史、产品族/SKU、周期、原始销售、原始入仓、退货数量、退货率、基准值、计算公式、绩效状态、证据来源、责任归属、改善记录和决策历史。

## 6. 非目标

M1 不建设完整库存系统、采购订单系统或自动工艺能力判定；货盘报价在已确认时作为成本基准证据保留。聚水潭 ERP 成本价只作为内部经营参考。
