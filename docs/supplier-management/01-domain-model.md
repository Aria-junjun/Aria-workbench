# 供应商领域模型与统一术语

## 1. 核心对象

| 术语 | 定义 | 关键关系 |
|---|---|---|
| 产品族 Product Family | 面向经营决策的主品集合，不等同于名称相同 | 包含多个经营产品编码 |
| 商品编码 SKU Code | 聚水潭或内部系统中的具体编码 | 归属于一个经营产品编码 |
| 经营产品编码 Operating Product Code | 用于销售分析和主品决策的基础编码 | 可对应多个变量 SKU |
| 供应商 Supplier | 具备合作、供货或候选资格的外部主体 | 通过供应关系连接产品族 |
| 供应关系 Supplier Assignment | 供应商与产品族的主供/备供关系 | 有角色、生效期、证据和变更历史 |
| 经营事实 Operating Fact | 销售、入仓、退货等原始业务事实 | 按期间、编码、产品族和供应商聚合 |
| 绩效基准 Performance Baseline | 判断达标与否的约定或公司标准 | 被绩效指标引用 |
| 绩效指标 KPI | 由事实和基准计算出的结果 | 产生状态和证据 |
| 改善事项 Corrective Action | 针对异常制定的改进任务 | 有节点、截止日期和验收结果 |
| 决策动作 Decision Action | 保持主供、备供、复核、改善或淘汰 | 必须关联证据 |
| 证据 Evidence | 表格、聊天、订单、验收或人工确认记录 | 支撑关系、指标和决策 |

## 2. 关系模型

```text
产品族 1 ── N 经营产品编码 1 ── N SKU
产品族 1 ── N 供应关系 N ── 1 供应商
供应关系 1 ── N 经营事实
经营事实 + 绩效基准 ──> 绩效指标 ──> 决策动作
决策动作 1 ── N 证据/改善事项
```

## 3. 约束

- 同一产品族、同一生效期最多一个有效主供；备供可以有多个。
- 供应关系变更不删除历史记录，只结束旧记录并新增新记录。
- SKU 归并只影响经营分析，不修改原始 SKU 编码。
- 货盘关联属于报价和成本辅助关系，不参与销售/入仓基本闭环。
- 缺失基准值或缺失实际值时，指标状态为“无法判断”。
